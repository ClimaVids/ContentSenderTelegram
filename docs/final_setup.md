# راه‌اندازی نهایی

1. Secret `TELEGRAM_BOT_TOKEN` را با Token ربات `@Climavid_bot` تنظیم کنید.
2. ربات `@Climavid_bot` را به کانال `@climavids` اضافه کنید و Administrator با مجوز ارسال پیام کنید.
3. در چت خصوصی ربات، `/claim` را ارسال کنید.
4. سپس `/test` را بفرستید.
5. برای وضعیت: `/status`
6. برای گزارش: `/report`
7. برای لاگ: `/logs`
